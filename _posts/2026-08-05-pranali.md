# Complete Beginner's Guide to Pranali IFMS (DDO)

The **Pranali Integrated Financial Management System (IFMS)** is the online financial management platform used by the **Government of Sikkim** for budget management, sanction orders, bill preparation, treasury processing, salary bills, and payments.

This guide explains the complete workflow followed by a Drawing and Disbursing Officer (DDO), based on practical office procedures.

> **Portal**
>
> - DDO Portal: https://ddo.pranali.sikkim.nic.in
> - Treasury/RCO Portal: https://rco.pranali.sikkim.nic.in

---

# Overview of the Workflow

The normal workflow is:

```
Budget Availability
        │
        ▼
Prepare Sanction Order
        │
        ▼
Generate & Sign Sanction
        │
        ▼
Prepare Bill
        │
        ▼
Generate TEO (where applicable)
        │
        ▼
Generate Top Sheet
        │
        ▼
Submit to Treasury (RCO)
        │
        ▼
Treasury Verification
        │
        ▼
Payment Released
```

# Logging into Pranali

Open your preferred browser.

Visit

```
https://ddo.pranali.sikkim.nic.in
```

Enter

- Username
- Password
- Captcha

Click **Login**.

After successful authentication, the DDO Dashboard opens.

---

# Module 1 – Preparing a Sanction Order

A sanction order authorizes expenditure before any bill can be prepared.

Navigate to

```
DDO
    ↓
Sanction Order
    ↓
Prepare Sanction
```

---

## Fill the Required Details

Enter:

- File Number
- Sanction Date
- Sanction Amount

Example

| Field | Example |
|--------|----------|
| File No | EDN/45/2026 |
| Date | 05-08-2026 |
| Amount | ₹1,25,000 |

---

## Enter Sanction Details

Provide:

- Purpose
- Description
- Scheme
- Department
- Beneficiary (if required)

---

## Select Sanction Type

Choose the appropriate sanction type according to departmental instructions.

Examples include:

- Original
- Revised
- Lapsed
- Others

Always verify with departmental guidelines.

---

## Work Type

According to the office practice noted:

**Always choose**

```
Single
```

unless specifically instructed otherwise.

---

## Select Budget Head

Choose the correct Budget Head.

Selecting an incorrect Budget Head may result in rejection.

---

## Enter DDO Code

Select or enter your DDO Code.

Example

```
060001
```

Use the code assigned to your office.

---

## Save and Sign

After verifying all entries,

Click

```
Save
```

Then

```
Sign
```

if Digital Signature is enabled.

---

## Print Copies

Print

```
3 Copies
```

These are generally required for office records and processing.

---

# Module 2 – Bill Preparation

Once the sanction order is complete, prepare the bill.

Navigate to

```
DDO
    ↓
Prepare Bill
```

---

## Choose Bill Type

Select the appropriate bill category.

Examples include

- Office Expense
- Contingency
- Salary
- Medical
- LTC
- Electricity
- Telephone
- Others

---

## Add New Bill

Click

```
Add New Bill
```

---

## Link the Sanction Order

Select the sanction order prepared earlier.

The bill should reference:

- Sanction Number
- Sanction Date

---

## Enter Bill Details

Fill

- Amount
- Description
- Payee
- Bill Period
- Budget Head

Verify all information before saving.

---

# TEO Entry

Where applicable,

Choose

```
Debit to Credit
```

This is referred to in office practice as:

```
TEO
```

Ensure the entries match the approved sanction.

---

# Print the Bill

Office practice recommends

### TEO

Print

```
3 Copies
```

### Other Bills

Print

```
2 Copies
```

---

# Module 3 – Salary Bill Preparation

Salary bills follow a separate workflow.

Navigate to

```
DDO
    ↓
Salary
        ↓
Salary Bill
```

---

## Select Employee Category

Choose

### 01

Regular Employee

or

### 02

Adhoc Employee

---

## Verify Employee Data

Check

- Employee Name
- Designation
- Pay Level
- Basic Pay
- Allowances
- Deductions
- Bank Details

---

## Generate Salary Bill

After verification,

Generate the bill.

Review

- Gross Salary
- Total Deductions
- Net Salary

Save and print.

---

# Module 4 – Top Sheet Generation

Once the bill is ready, generate the Top Sheet.

Navigate to

```
DDO
    ↓
Generate Top Sheet
```

---

## Select Messenger

Choose the messenger responsible for forwarding the bill.

---

## Select Bill Number

Choose the bill prepared earlier.

---

## Generate

Click

```
Generate Top Sheet
```

---

## View Details

Review

- Bill Number
- Amount
- Department
- Date

---

## Print

Print

```
1 Copy Only
```

---

# Submission to Treasury

Submit the following documents.

- Sanction Order
- Bill
- TEO (if applicable)
- Top Sheet
- Supporting Documents

These are forwarded to the Treasury through the prescribed process.

---

# Treasury (RCO) Processing

Treasury officials verify

- Budget availability
- DDO authorization
- Sanction validity
- Supporting documents
- Bill correctness

If everything is correct,

Payment is processed.

# Budget Head

Always verify the Budget Head before generating the bill.

Incorrect Budget Heads are among the most common reasons for rejection.

- Wrong DDO Code

# Practical Example

Suppose your office needs to purchase office furniture.

The workflow would be

1. Prepare the sanction order.
2. Enter file number and amount.
3. Select Budget Head.
4. Save and Sign.
5. Print three copies.
6. Prepare a new bill.
7. Attach the sanction order.
8. Generate TEO if applicable.
9. Print required copies.
10. Generate the Top Sheet.
11. Print one copy.
12. Submit the complete file to Treasury.

# Frequently Asked Questions

## How many copies of the Sanction Order should be printed?

Three copies.

---

## How many copies of TEO should be printed?

Three copies.

---

## How many copies of other bills should be printed?

Two copies.

---

## How many copies of the Top Sheet should be printed?

One copy.

---

## Which Work Type should normally be selected?

Single.

---

## Is stamp duty required?

According to the office notes used in this guide, no stamp duty is required for TEO or bill types. Users should always verify the latest Finance Department instructions.

# Final Thoughts

Pranali IFMS has streamlined the financial workflow of the Government of Sikkim by integrating sanction orders, bill preparation, salary processing, treasury verification, and payment into a single digital platform.

Following the correct sequence—Sanction Order → Bill Preparation → Top Sheet Generation → Treasury Submission—helps ensure faster processing and minimizes errors or bill rejections.

As departmental procedures and portal features may evolve over time, always refer to the latest circulars and instructions issued by the Finance Department, Government of Sikkim, and consult your departmental accounts office whenever clarification is needed.
